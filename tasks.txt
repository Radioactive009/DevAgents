Interactive Educational Games	Typing speed tester, flashcard quiz app, memory match game, chess puzzle board	Game loop logic, scoring algorithms, interactive animations, sound/UI states

text
Task Description:
Build a modern Markdown Live Preview editor with a split-screen view. The left pane should have an input textarea with syntax formatting buttons (bold, italic, code block), and the right pane should render the parsed HTML in real time with styled typography. Include a word counter and character counter at the bottom.
Requirements:
- Split-screen responsive layout with dark theme
- Real-time markdown parsing to HTML
- Toolbar for bold, italic, headings, and code blocks
- Live word and character count status bar
- Automated unit tests validating the markdown parsing functions
2. Python Packages, CLI Tools & Algorithms (With Automated Pytest Suites)
DevAgents includes built-in sandboxed Python execution that runs pytest, captures failure traces, and triggers the autonomous debugging agent to self-heal broken tests:

Project Type	Example Features	What Gets Generated
Data Structures & Algorithms	Trie autocomplete, graph pathfinder (Dijkstra/A*), LRU cache, binary search tree	Pure Python module, docstrings, edge-case unit test suites (pytest)
Data Validation & Parsing	Custom schema validator, CSV/JSON parser, formula evaluator	Type-annotated classes, custom exception hierarchies, extensive test coverage
Financial & Math Engines	Loan amortizer, compound interest calculator, statistical analysis toolkit	Modular functions, numerical precision checks, parametrized tests
Ready-to-Test Prompt (Copy & Paste):
text
Task Description:
Build a thread-safe in-memory key-value cache library in Python that supports Time-To-Live (TTL) expiration per key, Least Recently Used (LRU) eviction when reaching max capacity, and a bulk get/set API.
Requirements:
- Cache class with configurable max_size and default_ttl
- O(1) get and set operations using a doubly linked list and hash map
- Automatic eviction of expired keys on access
- Thread-safe access using locks
- Comprehensive pytest test suite testing TTL expiration, LRU eviction order, and concurrency
